A project referenced by identifier, with additional parameters.

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`id`](#id) | [`Id`](./Id.mdx) | Identifier of the depended on project. |
| [`scope`](#scope) | [`DependencyScope`](./DependencyScope.mdx) | Scope of the dependency relationship. |
| [`source`](#source) | [`DependencySource`](./DependencySource.mdx) | Source of where the dependency came from. |
| [`via`](#via) | `string` | Metadata about the source. |

## Properties

### `id`

> **Required**

Identifier of the depended on project.

| Attribute | Value |
| --- | --- |
| Type | [`Id`](./Id.mdx) |

### `scope`

> **Required**

Scope of the dependency relationship.

| Attribute | Value |
| --- | --- |
| Type | [`DependencyScope`](./DependencyScope.mdx) |
| Default | `"production"` |
| Values | `"build"`, `"development"`, `"peer"`, `"production"`, `"root"` |

### `source`

> **Required**

Source of where the dependency came from.

| Attribute | Value |
| --- | --- |
| Type | [`DependencySource`](./DependencySource.mdx) |
| Default | `"explicit"` |
| Values | `"explicit"`, `"implicit"` |

### `via`

> **Optional** · **Nullable**

Metadata about the source.

| Attribute | Value |
| --- | --- |
| Type | `string` |
