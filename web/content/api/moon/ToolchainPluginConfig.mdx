Configures an individual toolchain.

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`config`](#config) | `Record<string, unknown>` | Arbitrary configuration that'll be passed to the WASM plugin. |
| [`inheritAliases`](#inheritaliases) | `boolean` | Inherit aliases (name derived from a manifest) for all projects associated with this toolchain. @since 2.1.0 |
| [`installDependencies`](#installdependencies) | `boolean` | Run the `InstallDependencies` actions for each running task when changes to lockfiles and manifests are detected. @since 2.1.0 |
| [`plugin`](#plugin) | [`PluginLocator`](./PluginLocator.mdx) | Location of the WASM plugin to use. |
| [`version`](#version) | [`UnresolvedVersionSpec`](./UnresolvedVersionSpec.mdx) | The version of the toolchain to download and install. |
| [`versionFromPrototools`](#versionfromprototools) | [`ToolchainPluginVersionFrom`](./ToolchainPluginVersionFrom.mdx) | Inherit the version from the root `.prototools`. When true, matches using the same identifier, otherwise a string can be provided for a custom identifier. |

## Properties

### `config`

> **Flattened**

Arbitrary configuration that'll be passed to the WASM plugin.

| Attribute | Value |
| --- | --- |
| Type | `Record<string, unknown>` |

### `inheritAliases`

> **Optional**

Inherit aliases (name derived from a manifest) for all
projects associated with this toolchain.
@since 2.1.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Default | `true` |

### `installDependencies`

> **Optional**

Run the `InstallDependencies` actions for each running task
when changes to lockfiles and manifests are detected.
@since 2.1.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Default | `true` |

### `versionFromPrototools`

> **Required**

Inherit the version from the root `.prototools`.
When true, matches using the same identifier, otherwise a
string can be provided for a custom identifier.

| Attribute | Value |
| --- | --- |
| Type | [`ToolchainPluginVersionFrom`](./ToolchainPluginVersionFrom.mdx) |
