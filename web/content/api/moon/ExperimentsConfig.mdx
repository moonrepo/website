---
title: ExperimentsConfig
---

Configures experiments across the entire moon workspace.

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`asyncAffectedTracking`](#asyncaffectedtracking) | `boolean` | Track and determine affected projects and tasks asynchronously. @since 2.2.0 |
| [`asyncGraphBuilding`](#asyncgraphbuilding) | `boolean` | Build the project and task graphs asynchronously. @since 2.2.0 |
| [`casOutputsCache`](#casoutputscache) | `boolean` | Store task outputs in a local CAS (content-addressable storage) cache. @since 2.3.0 |
| [`nativeFileHashing`](#nativefilehashing) | `boolean` | Use native file hashing instead of using the VCS. @since 2.3.0 |

## Properties

### `asyncAffectedTracking`

> **Optional**

Track and determine affected projects and tasks asynchronously.
@since 2.2.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Default | `true` |
| Environment variable | `MOON_EXPERIMENT_ASYNC_AFFECTED_TRACKING` |

### `asyncGraphBuilding`

> **Optional**

Build the project and task graphs asynchronously.
@since 2.2.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Default | `true` |
| Environment variable | `MOON_EXPERIMENT_ASYNC_GRAPH_BUILDING` |

### `casOutputsCache`

> **Required**

Store task outputs in a local CAS (content-addressable storage) cache.
@since 2.3.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Environment variable | `MOON_EXPERIMENT_CAS_OUTPUTS_CACHE` |

### `nativeFileHashing`

> **Optional**

Use native file hashing instead of using the VCS.
@since 2.3.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Default | `true` |
| Environment variable | `MOON_EXPERIMENT_NATIVE_FILE_HASHING` |
