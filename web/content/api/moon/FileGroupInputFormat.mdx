---
title: FileGroupInputFormat
---

Available formats to resolve the file group into.

## Variants

| Variant | Value | Tags | Description |
| --- | --- | --- | --- |
| `static` | `"static"` | **Default** | Return the group as-is. |
| `dirs` | `"dirs"` |  | Return only directories. |
| `envs` | `"envs"` |  | Return only environment variables. |
| `files` | `"files"` |  | Return only files. |
| `globs` | `"globs"` |  | Return only globs. |
| `root` | `"root"` |  | Return the lowest common root of all paths. |
