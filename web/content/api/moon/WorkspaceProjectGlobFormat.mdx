---
title: WorkspaceProjectGlobFormat
---

The project identifier format for glob located projects.

## Variants

| Variant | Value | Tags | Description |
| --- | --- | --- | --- |
| `dir-name` | `"dir-name"` | **Default** | The project directory name. |
| `source-path` | `"source-path"` |  | The relative path from the workspace root to the project root. |
