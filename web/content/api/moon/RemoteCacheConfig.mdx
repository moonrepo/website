---
title: RemoteCacheConfig
---

Configures the action cache (AC) and content-addressable cache (CAS).
@since 1.30.0

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`compression`](#compression) | [`RemoteCompression`](./RemoteCompression) | The compression format to use when uploading/downloading blobs. @since 1.31.0 |
| [`instanceName`](#instancename) | `string` | Unique instance name for blobs. Will be used as a folder name. |
| [`localReadOnly`](#localreadonly) | `boolean` | When local, only download matching blobs and do not upload new blobs. Blobs will only be uploaded in CI environments. @since 1.40.0 |
| [`verifyIntegrity`](#verifyintegrity) | `boolean` | When downloading blobs, verify the digests/hashes in the response match the associated blob contents. This will reduce performance but ensure partial or corrupted blobs won't cause failures. @since 1.36.0 |

## Properties

### `compression`

> **Required**

The compression format to use when uploading/downloading blobs.
@since 1.31.0

| Attribute | Value |
| --- | --- |
| Type | [`RemoteCompression`](./RemoteCompression) |
| Default | `"none"` |
| Values | `"none"`, `"zstd"` |
| Environment variable | `MOON_REMOTE_CACHE_COMPRESSION` |

### `instanceName`

> **Optional**

Unique instance name for blobs. Will be used as a folder name.

| Attribute | Value |
| --- | --- |
| Type | `string` |
| Default | `"moon-outputs"` |
| Environment variable | `MOON_REMOTE_CACHE_INSTANCE_NAME` |

### `localReadOnly`

> **Optional**

When local, only download matching blobs and do not upload new
blobs. Blobs will only be uploaded in CI environments.
@since 1.40.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Environment variable | `MOON_REMOTE_CACHE_LOCAL_READ_ONLY` |

### `verifyIntegrity`

> **Optional**

When downloading blobs, verify the digests/hashes in the response
match the associated blob contents. This will reduce performance
but ensure partial or corrupted blobs won't cause failures.
@since 1.36.0

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Environment variable | `MOON_REMOTE_CACHE_VERIFY_INTEGRITY` |
