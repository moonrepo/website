---
title: DockerScaffoldConfig
---

Configures aspects of the Docker scaffolding process.
When configured at the workspace-level, applies to all projects,
but can be overridden at the project-level.

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`configsPhaseGlobs`](#configsphaseglobs) | `string[]` | List of glob patterns in which to include/exclude files in the "configs" skeleton. Applies to both project and workspace level scaffolding. @since 2.0.0 |
| [`sourcesPhaseGlobs`](#sourcesphaseglobs) | `string[]` | List of glob patterns in which to include/exclude files in the "sources" skeleton. Applies to both project and workspace level scaffolding. @since 2.0.0 |
