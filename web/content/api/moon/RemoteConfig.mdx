title: RemoteConfig

Configures the remote service, powered by the Bazel Remote Execution API.
@since 1.30.0

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`api`](#api) | [`RemoteApi`](./RemoteApi) | The API format of the remote service. @since 1.32.0 |
| [`auth`](#auth) | [`RemoteAuthConfig`](./RemoteAuthConfig) | Connect to the host using basic HTTP authentication. @since 1.32.0 |
| [`cache`](#cache) | [`RemoteCacheConfig`](./RemoteCacheConfig) | Configures the action cache (AC) and content-addressable cache (CAS). |
| [`host`](#host) | `string` | The remote host to connect and send requests to. Supports gRPC protocols. |
| [`mtls`](#mtls) | [`RemoteMtlsConfig`](./RemoteMtlsConfig) | Connect to the host using server and client authentication with mTLS. This takes precedence over normal TLS. |
| [`tls`](#tls) | [`RemoteTlsConfig`](./RemoteTlsConfig) | Connect to the host using server-only authentication with TLS. |

## Properties

### `api`

> **Required**

The API format of the remote service.
@since 1.32.0

| Attribute | Value |
| --- | --- |
| Type | [`RemoteApi`](./RemoteApi) |
| Default | `"grpc"` |
| Values | `"grpc"`, `"http"` |
| Environment variable | `MOON_REMOTE_API` |
