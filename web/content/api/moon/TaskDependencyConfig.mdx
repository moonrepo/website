A task referenced by target, with additional parameters to pass through.

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`args`](#args) | `string[]` | Additional arguments to pass to this dependency when it's ran. |
| [`cacheStrategy`](#cachestrategy) | [`TaskDependencyCacheStrategy`](./TaskDependencyCacheStrategy) | Controls how this dependency invalidates the current task's cache. When omitted, defaults to `hash` if the dependency declares outputs, otherwise `ignored`. @since 2.3.0 |
| [`env`](#env) | `Record<string, string \| null>` | A map of environment variables specific to this dependency. |
| [`optional`](#optional) | `boolean` | Marks the dependency as optional when being inherited from the top-level. @since 1.20.0 |
| [`target`](#target) | `string` | The target of the depended on task. |
