---
title: moon toolchain
---

Manage [toolchain](<../(fundamentals)/toolchain.mdx>) plugins, WASM plugins that teach moon how to detect, install, and
run a language or platform's tooling (Node.js, Rust, Python, and so on).

This is a parent command and does nothing on its own; use one of the following subcommands:

- [`moon toolchain add`](./toolchain/add.mdx) - Add and configure a toolchain plugin in
  [`.moon/toolchains.config`](<../(fundamentals)/toolchain.mdx>).
- [`moon toolchain download`](./toolchain/download.mdx) - Download and cache the WASM plugins for all configured toolchains,
  without executing them.
- [`moon toolchain info`](./toolchain/info.mdx) - Inspect a registered (or ad-hoc) toolchain's
  metadata, configuration schema, and supported APIs.

```shell
$ moon toolchain add node
$ moon toolchain info node
$ moon toolchain download
```
