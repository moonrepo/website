---
title: moon generate
---

Generate and scaffold files from a pre-defined template.

## Arguments

- `[ID]`: Template ID to generate
- `[VARS]...`: Arguments to define as variable values

## Options

- `--to <DEST>`: Destination path, relative from workspace root or working directory
- `--defaults`: Use the default value of all variables instead of prompting
- `--dry-run`: Run entire generator process without writing files
- `--force`: Force overwrite any existing files at the destination
- `--template`: Create a new template
- `-h, --help`: Print help
- `-V, --version`: Print version
