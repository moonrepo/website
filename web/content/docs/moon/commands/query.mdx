---
title: moon query
---

Query information about moon, your workspace, and the current VCS state, and print the result as
JSON to stdout. Every `moon query` subcommand is designed to be piped into other tools (`jq`,
scripts, editor integrations, CI systems) or chained into other `moon query` calls, since they all
speak the same JSON format.

This command is aliased as `moon q`, and does nothing on its own — it exists purely to group the
following subcommands:

- [`moon query affected`](./query/affected) - Query the projects and tasks affected by changed
  files.
- [`moon query changed-files`](./query/changed-files) - Query the list of files changed against the
  current VCS state.
- [`moon query projects`](./query/projects) - Query and filter the projects in the project graph.
- [`moon query tasks`](./query/tasks) - Query and filter the tasks in the task graph, grouped by
  project.

```shell
$ moon query projects
$ moon query tasks --id build
$ moon query changed-files --status added --status modified
$ moon query affected --upstream deep
```

[`moon query projects`](./query/projects) and [`moon query tasks`](./query/tasks) both also accept a
[query language (MQL)](../advanced/query-lang) statement as an argument, for more advanced and
composable filtering than the individual `--option` flags provide.
