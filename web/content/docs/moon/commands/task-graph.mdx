---
title: moon task-graph
---

Display an interactive graph of tasks.

## Arguments

- `[TARGET]`: Task target to *only* graph

## Options

- `--dependents`: Include direct dependents of the focused target
- `--host <HOST>`: The host address [env: MOON_HOST=] [default: 127.0.0.1]
- `--port <PORT>`: The port to bind to [env: MOON_PORT=] [default: 0]
- `--dot`: Print the graph in DOT format
- `--json`: Print the graph in JSON format
- `-h, --help`: Print help
- `-V, --version`: Print version
