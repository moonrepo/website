---
title: moon extension add
---

Add and configure an extension plugin.

## Arguments

- `<ID>`: Unique ID of the extension to add
- `[PLUGIN]`: Plugin locator string to find and load the extension

## Options

- `--minimal`: Add with minimal configuration and prompts
- `--yes`: Skip prompts and use default values
- `-h, --help`: Print help
- `-V, --version`: Print version
