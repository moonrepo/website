---
title: moon extension info
---

Show detailed information about an [extension](../extension) plugin, without executing it. This
command downloads (or loads from cache) the extension's WASM plugin and renders:

- The extension's title, description, and plugin version.
- Its configuration schema, if the plugin defines one via `define_extension_config`.
- A list of every extension-related API, whether the plugin implements it, and whether it's
  required (`register_extension` is always required).

This is useful for auditing what an extension actually supports and does before wiring it up with
[`moon extension add`](./add) or running it with [`moon ext`](../ext).

Just like [`moon extension add`](./add), the `plugin` argument can be omitted for moon's built-in
extensions (`download`, `migrate-nx`, `migrate-turborepo`, and `unpack`), since their locators are
already known. For any other extension, either configure it in [`.moon/extensions.*`](../../extension) first, or
pass its plugin locator explicitly.

```shell
$ moon extension info download
$ moon extension info my-extension https://example.com/path/to/plugin.wasm
```

## Arguments

- `<ID>` - ID of the extension to inspect. If already configured in [`.moon/extensions.*`](../../extension), its
  locator will be resolved automatically.
- `[PLUGIN]` - Plugin locator string used to locate and load the extension's WASM file, when not
  already configured or not a built-in extension.
