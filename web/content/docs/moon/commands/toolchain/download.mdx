---
title: moon toolchain download
---

Download the WASM plugin for every [toolchain](../../toolchain) configured in
[`.moon/toolchains.config`](../../toolchain), one of the [`moon toolchain`](../toolchain) management
commands. This is purely a plugin-fetching step: for each
configured toolchain, moon resolves its plugin locator, downloads the `.wasm` file (or reuses it
from the local cache if already present), and registers the plugin so it's ready to be used.

```shell
$ moon toolchain download
```

If no toolchain plugins are configured for the workspace, the command does nothing and prints an
informational notice instead of failing.

This is distinct from [`moon setup`](../setup), which installs the actual language or tool
versions that a toolchain manages (for example, downloading and installing a specific Node.js or
Rust version). `moon toolchain download` never touches installed tool versions; it only ensures
the plugins themselves (the WASM code that implements toolchain behavior) are downloaded and
cached locally. In practice, you'll typically run [`moon setup`](../setup) instead, as it downloads
plugins as a side effect of installing toolchains.

Because moon already downloads a toolchain's plugin the first time it's needed, you'll rarely have
to run this command manually. It's most useful for warming the plugin cache ahead of time, such as
in a CI job or Docker image build step, or to ensure everything is available before working
offline.

To inspect a single plugin's capabilities instead of downloading every configured one, use
[`moon toolchain info`](./info). To add and configure a new toolchain plugin, use
[`moon toolchain add`](./add).
