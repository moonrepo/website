---
title: moon toolchain add
---

Add and configure a toolchain plugin.

## Arguments

- `<ID>`: Unique ID of the toolchain to add
- `[PLUGIN]`: Plugin locator string to find and load the toolchain

## Options

- `--minimal`: Add with minimal configuration and prompts
- `--yes`: Skip prompts and use default values
- `-h, --help`: Print help
- `-V, --version`: Print version
