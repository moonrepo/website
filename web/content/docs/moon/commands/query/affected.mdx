---
title: moon query affected
---

Query affected status for projects and tasks.

## Arguments

- `[BY]`: Conditions in which to track affected

## Options

- `--downstream <DOWNSTREAM>`: Include downstream dependents [default: none] [aliases: --dependents] [possible values: none, direct, deep]
- `--upstream <UPSTREAM>`: Include upstream dependencies [default: none] [aliases: --dependencies] [possible values: none, direct, deep]
- `-h, --help`: Print help
- `-V, --version`: Print version
