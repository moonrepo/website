---
title: proto plugin search
---

Search proto's [third-party plugin registry](<../../(fundamentals)/(plugin)/tool.mdx#third-party-tools>)
for a plugin that provides a tool, and print the [locator](../../../../wasm/docs/plugin-locators.mdx)
needed to enable it. Reach for this when a tool isn't
[built in](<../../(fundamentals)/(plugin)/tool.mdx#built-in-tools>) or available as a
[community tool](<../../(fundamentals)/(plugin)/tool.mdx#community-tools>), which already work by ID
and aren't searched. Before you write a [plugin](<../../(fundamentals)/(plugin)/plugin.mdx>) of your
own, check whether someone has already published one.

```shell
# Search by ID, name, or description
$ proto plugin search terraform

# Matching is case-sensitive, so match the casing used in descriptions
$ proto plugin search Kubernetes

# Quote queries with spaces, which are matched as a whole phrase
$ proto plugin search "secret scanner"

# Register a plugin from the results, under an ID of your choosing, and install it
$ proto plugin add example "github://org/proto-example-tool"
$ proto install example
```

A plugin matches when its ID, name, or description contains the query, exactly as typed. Matching
is case-sensitive, with no fuzzy matching, so short queries work best, like part of a tool's name.

Each result shows the plugin's name, author,
[format](<../../(fundamentals)/(plugin)/plugin.mdx#plugin-formats>), description, and locator. The
same tool can have more than one plugin, so compare the author and format before you pick one. Then
register it with [`proto plugin add`](./add.mdx), and install it with
[`proto install`](../install.mdx). Third-party plugins run code on your machine and are maintained by
their authors, so check a plugin's source before you add it.

The command exits with a non-zero code when nothing matches. Pass the global
[`--json`](../overview.mdx#global-options) option to print the full registry entry of each match
instead, which prints `[]` and exits successfully when nothing matches.

## Arguments

- `<QUERY>` - The text to search for. A plugin matches when its ID, name, or description contains
  this text, with the same casing. Wrap it in quotes when it contains spaces.
