---
title: proto mcp
---

Start a [Model Context Protocol](https://modelcontextprotocol.io/) (MCP) server, so that AI agents
and editors can manage your toolchain through proto. The server lets an agent install and uninstall
versions of a [tool](<../(fundamentals)/(plugin)/tool.mdx>), list a tool's available versions, and
read configuration, as structured equivalents of [`proto install`](./install.mdx),
[`proto uninstall`](./uninstall.mdx), [`proto versions`](./versions.mdx),
[`proto debug config`](./debug/config.mdx), and [`proto debug env`](./debug/env.mdx). The MCP guide
describes every [tool](../guides/mcp.mdx#available-tools) and
[resource](../guides/mcp.mdx#available-resources).

You rarely run this command yourself. Your MCP client spawns `proto mcp` and talks to it over stdin
and stdout (see [setup](../guides/mcp.mdx#setup) for registering it with your client). Started by
hand, it prints nothing and waits for a client to send messages.

Configuration is loaded once, at startup, relative to the directory the client starts the server in
(usually the open project), in the [`upwards-global`](<../(fundamentals)/config.mdx#upwards-global>)
resolution mode unless you pass [`--config-mode`](./overview.mdx#global-options). So changes to a
[`.prototools`](<../(fundamentals)/config.mdx>), including a version pinned through the server
itself, aren't visible to the agent until the client restarts the server.

```shell
# Start the server (normally spawned by your MCP client)
$ proto mcp

# Print the server's information, tools, and resources, then exit
$ proto mcp --info

# Start the server, and write debug logs to a file
$ proto mcp --log debug --log-file ./proto-mcp.log
```

## Options

- `--info` - Print the server's instructions for agents, the proto version, the MCP protocol
  versions it supports, and every tool and resource it exposes, then exit, instead of starting the
  server. Use it to check what an agent will have access to, without connecting a client. Pass
  [`--json`](./overview.mdx#output-formats) for machine-readable output.
