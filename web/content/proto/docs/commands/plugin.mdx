---
title: proto plugin
---

Manage the [plugins](<../(fundamentals)/(plugin)/plugin.mdx>) that power proto's
[tools](<../(fundamentals)/(plugin)/tool.mdx>) and [backends](<../(fundamentals)/(plugin)/backend.mdx>).
Built-in and [community tools](<../(fundamentals)/(plugin)/tool.mdx#community-tools>) work without
any setup, so you'll mostly reach for these commands when you need something else: finding a
plugin for a tool that proto doesn't support out of the box, registering it in a
[`.prototools`](<../(fundamentals)/config.mdx>) file without editing the file by hand, or checking
which plugin a tool is actually loaded from, like when a configured plugin
[overrides a built-in one](<../(fundamentals)/(plugin)/tool.mdx#overriding-built-in-tools>).

This command does nothing on its own. It exists purely to group the following sub-commands:

- [`proto plugin add`](./plugin/add.mdx) - Register a tool or backend plugin in a
  [`.prototools`](<../(fundamentals)/config.mdx>) file, with an ID and a
  [locator](../../../wasm/docs/plugin-locators.mdx), and load it to verify that it works.
- [`proto plugin info`](./plugin/info.mdx) - Display details about a single tool's plugin, like its
  locator and version, the detected version, installed versions, executables, and
  [store](<../(fundamentals)/store.mdx>) directories.
- [`proto plugin list`](./plugin/list.mdx) - List the built-in tool plugins and those configured in
  the global [`.prototools`](<../(fundamentals)/config.mdx>) with their locators, and optionally
  each tool's installed versions and aliases.
- [`proto plugin remove`](./plugin/remove.mdx) - Remove a plugin from a
  [`.prototools`](<../(fundamentals)/config.mdx>) file, along with the tool's version pin and
  settings.
- [`proto plugin search`](./plugin/search.mdx) - Search the third-party plugin registry by ID, name,
  or description, and print the locator of each match.

```shell
# Find a plugin, register it in the closest .prototools, and install the tool
$ proto plugin search example
$ proto plugin add example "github://org/proto-example-tool"
$ proto install example

# Inspect a tool's plugin, and list tool plugins with their installed versions
$ proto plugin info node
$ proto plugin list --versions
```

Plugin locators are a [security-sensitive setting](<../(fundamentals)/trust.mdx#security-sensitive-settings>),
as plugins execute code on your machine. When [`proto plugin add`](./plugin/add.mdx) writes the
first one to a [`.prototools`](<../(fundamentals)/config.mdx>) file, proto
[trusts that file](<../(fundamentals)/trust.mdx#automatically-trusted>) automatically, since you
added the plugin yourself.

[`proto plugin info`](./plugin/info.mdx), [`proto plugin list`](./plugin/list.mdx), and
[`proto plugin search`](./plugin/search.mdx) also support the global
[`--json`](./overview.mdx#global-options) option, which prints the result as JSON for scripts and
other tools.
