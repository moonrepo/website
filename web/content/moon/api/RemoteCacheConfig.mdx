---
title: RemoteCacheConfig
---

> **Since** (1.30.0)

Configures the action cache (AC) and content-addressable cache (CAS).

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`compression`](#compression) | [`RemoteCompression`](./RemoteCompression.mdx) | The compression format to use when uploading/downloading blobs. |
| [`instanceName`](#instancename) | `string` | Unique instance name for blobs. Will be used as a folder name. |
| [`localReadOnly`](#localreadonly) | `boolean` | When local, only download matching blobs and do not upload new blobs. Blobs will only be uploaded in CI environments. |
| [`retryCount`](#retrycount) | `number` | The maximum number of times to retry a request that failed with a transient error (connection failure, timeout, 5xx, 429, etc), using exponential backoff. Only applies to HTTP APIs. |

## Properties

### `compression`

> **Required** · **Since** (1.31.0)

The compression format to use when uploading/downloading blobs.

| Attribute | Value |
| --- | --- |
| Type | [`RemoteCompression`](./RemoteCompression.mdx) |
| Default | `"none"` |
| Values | `"none"`, `"zstd"` |
| Environment variable | `MOON_REMOTE_CACHE_COMPRESSION` |

### `instanceName`

> **Optional**

Unique instance name for blobs. Will be used as a folder name.

| Attribute | Value |
| --- | --- |
| Type | `string` |
| Default | `"moon-outputs"` |
| Environment variable | `MOON_REMOTE_CACHE_INSTANCE_NAME` |

### `localReadOnly`

> **Required** · **Since** (1.40.0)

When local, only download matching blobs and do not upload new
blobs. Blobs will only be uploaded in CI environments.

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Environment variable | `MOON_REMOTE_CACHE_LOCAL_READ_ONLY` |

### `retryCount`

> **Optional** · **Since** (2.6.0)

The maximum number of times to retry a request that failed with
a transient error (connection failure, timeout, 5xx, 429, etc),
using exponential backoff. Only applies to HTTP APIs.

| Attribute | Value |
| --- | --- |
| Type | `number` |
| Default | `3` |
| Environment variable | `MOON_REMOTE_CACHE_RETRY_COUNT` |
