---
title: CacheCasConfig
---

Configures aspects of the content-addressable storage (CAS) cache.

## Index

| Property | Type | Description |
| --- | --- | --- |
| [`maxSize`](#maxsize) | `string` | Maximum total size of the local cache, for example "10gb" or "512mib". When exceeded, the least recently used cached task outputs are evicted. Unlimited when unset. |
| [`verifyIntegrity`](#verifyintegrity) | `boolean` | Verify hash on every read. When enabled, reads are slower but they detect on-disk corruption. |

## Properties

### `maxSize`

> **Optional** · **Nullable** · **Since** (2.4.0)

Maximum total size of the local cache, for example "10gb" or
"512mib". When exceeded, the least recently used cached task outputs
are evicted. Unlimited when unset.

| Attribute | Value |
| --- | --- |
| Type | `string` |
| Environment variable | `MOON_CACHE_CAS_MAX_SIZE` |

### `verifyIntegrity`

> **Required** · **Since** (2.3.0)

Verify hash on every read. When enabled, reads are slower
but they detect on-disk corruption.

| Attribute | Value |
| --- | --- |
| Type | `boolean` |
| Environment variable | `MOON_CACHE_CAS_VERIFY_INTEGRITY` |
