The pattern in which affected files will be passed to the affected task.

## Index

| Variant | Type | Description |
| --- | --- | --- |
| [`args`](#args) | `"args"` | Passed as command line arguments. |
| [`env`](#env) | `"env"` | Passed as environment variables. |
| [`enabled`](#enabled) | `boolean` | Passed as command line arguments and environment variables. |

## Variants

### `args`

| --- | --- |
