---
title: moon extension download
---

Download and cache every [extension](../extension.mdx) plugin currently configured in
[`.moon/extensions.config`](<../../(fundamentals)/extension.mdx>). Each configured plugin's locator is resolved, its `.wasm`
file is fetched (or verified against the existing cache), and the plugin is loaded and registered,
but it is _not_ executed. Only its `register_extension` function is called (to read its metadata),
and `execute_extension` never runs, so this is purely a fetch-and-cache operation. Learn more about
where plugins are cached, and when they're re-downloaded, in the
[plugin locators](../../../../wasm/docs/plugin-locators.mdx) docs.

This is handy for warming the plugin cache ahead of time, rather than paying the download cost on
first use. For example, in a CI pipeline or when [building a Docker image](../../guides/docker.mdx),
running this command as an early step ensures every extension is already cached before
[`moon ext`](../ext.mdx) is invoked later on, avoiding an extra network round trip mid-run. It's
also useful if you know you're about to go offline and want every configured extension available
locally beforehand, as plugins that have never been downloaded can't be loaded in
[offline mode](../../guides/offline-mode.mdx).

```shell
$ moon extension download
```

If no extensions are configured in [`.moon/extensions.config`](<../../(fundamentals)/extension.mdx>), an info notice is
printed and nothing is downloaded.
