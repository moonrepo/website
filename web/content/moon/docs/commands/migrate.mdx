---
title: moon migrate
---

Operations for migrating existing projects and workspaces to moon, or between major
versions of moon itself.

This is a parent command with the following subcommands:

- [`moon migrate v3`](./migrate/v3.mdx) - Migrate an existing moon v2 workspace to moon v3.
- [`moon migrate v2`](./migrate/v2.mdx) - Migrate an existing moon v1 workspace to moon v2.

```shell
$ moon migrate v3
```
