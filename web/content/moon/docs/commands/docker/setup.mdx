---
title: moon docker setup
---

Installs toolchains and dependencies for the projects that were previously scaffolded, acting
as an all-in-one replacement for manually running commands like `npm install`, `cargo fetch`, or
similar package manager commands within a `Dockerfile`. It runs after
[`moon docker scaffold`](./scaffold.mdx) in the [`moon docker`](../docker.mdx) workflow.

The command reads the `dockerManifest.json` file from the workspace root, which is written by
[`moon docker scaffold`](./scaffold.mdx) and lists which projects were explicitly focused on. If
this manifest doesn't exist, the command fails and suggests running [`moon docker scaffold`](./scaffold.mdx)
first. For each focused project, moon builds an [action graph](<../../(fundamentals)/action-graph.mdx>) that installs
the toolchain(s) and dependencies required by that project, then runs the action pipeline to
execute those actions.

This is intended to be run inside a `Dockerfile`, in the `build` stage, after the `configs`
skeleton from [`moon docker scaffold`](./scaffold.mdx) has been copied into the image, but before
the `sources` skeleton, so that the dependency layer is only invalidated when a manifest or
lockfile changes (see [scaffolding the repository](../../guides/docker.mdx#scaffolding-the-repository)).
Toolchains are installed through [proto](/proto/docs) by default; to use binaries that already
exist in the base image instead, see
[using system binaries](../../guides/docker.mdx#using-system-binaries).

```shell
$ moon docker setup
```
