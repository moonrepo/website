---
title: moon docker prune
---

Reduces the size of a Docker image by removing development artifacts and reinstalling
production-only dependencies for the projects that were previously scaffolded. This is intended
to be run inside a `Dockerfile`, after a project has been built, as the final step before the
`start` stage, and is the last of the [`moon docker`](../docker.mdx) commands to run.

The command reads the `dockerManifest.json` file from the workspace root, which is written by
[`moon docker scaffold`](./scaffold.mdx) and records which projects were explicitly focused on
versus pulled in as dependencies. If this manifest doesn't exist, the command fails and suggests
running [`moon docker scaffold`](./scaffold.mdx) first.

The focused projects are placed into the [layout graph](../../advanced/layout-graph.mdx), the same
way a run would, and for every dependencies root that they belong to (for example, a pnpm workspace
root, a Cargo workspace root, or a project's own package), moon runs the following steps,
processing roots in parallel. The unfocused projects that were scaffolded as dependencies are
matched against each root's members, and are included in that root as well. When none of the focused projects belong to a dependencies root,
there's nothing to prune, and the command does nothing.

1. Each toolchain plugin's own pruning logic runs first, which typically deletes vendor directories
   (like `node_modules`) and other files not needed at runtime, as controlled by the
   [`docker.prune.deleteVendorDirectories`](/moon/api/DockerPruneConfig#deletevendordirectories)
   setting.
2. If [`docker.prune.installToolchainDependencies`](/moon/api/DockerPruneConfig#installtoolchaindependencies)
   is enabled, dependencies are reinstalled with production-only flags, scoped to the focused
   projects, with the install output streamed to the console.

Both settings default to `true`, and are configured in
[`.moon/workspace.config`](<../../(fundamentals)/workspace.mdx>). See
[customizing pruning](../../guides/docker.mdx#customizing-pruning) for an example.

```shell
$ moon docker prune
```
