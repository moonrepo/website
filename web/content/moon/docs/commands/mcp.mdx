---
title: moon mcp
---

Start a [Model Context Protocol](https://modelcontextprotocol.io) (MCP) server that communicates
over stdio, allowing AI agents and editor assistants (Claude Code, Cursor, VS Code Copilot, Zed,
and others) to query and operate on your moon workspace directly. Refer to the
[MCP integration guide](../guides/mcp.mdx) for registering the server with each client.

```shell
$ moon mcp
```

This command is not meant to be run manually in a terminal. Instead, your editor or agent client
spawns `moon mcp` as a subprocess and communicates with it using the MCP protocol. When started,
the command loads the [workspace graph](<../(fundamentals)/workspace.mdx>) once, then blocks and
listens for tool requests on stdin/stdout until the parent process sends a shutdown signal, at
which point the server aborts and the command exits. Because the graph is only loaded on startup,
restart the server from your client after changing configuration.

The workspace is located by searching upwards from the server's working directory. When the client
doesn't start the server within your repository (for example, with a global configuration), set
the `MOON_WORKSPACE_ROOT` environment variable to the absolute path of the workspace.

```json
{
  "mcpServers": {
    "moon": {
      "command": "moon",
      "args": ["mcp"],
      "env": {
        "MOON_WORKSPACE_ROOT": "/absolute/path/to/your/moon/workspace"
      }
    }
  }
}
```

The server implements the stateless MCP `2026-07-28` protocol. Older protocol versions
(`2025-11-25` and below), and the `initialize` handshake they require, aren't supported, so make
sure your MCP client is up to date.

Once registered, the server exposes tools for reading projects, tasks,
[templates](../guides/codegen.mdx), and changed files, and for syncing projects and the
workspace, and generating code with [`moon generate`](./generate.mdx). Because the server is just
another moon process, these tools respect the same [`.moon`](<../(fundamentals)/config.mdx>)
configuration, toolchains, and project/task graph as running the equivalent command directly. See
the guide's [available tools](../guides/mcp.mdx#available-tools) for each tool and its inputs, and
[troubleshooting](../guides/mcp.mdx#troubleshooting) for debugging the server.
