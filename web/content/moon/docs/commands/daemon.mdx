---
title: moon daemon
---

Manage moon's background daemon process (alias: `d`).

The [daemon](../guides/daemon.mdx) is a long-lived, per-workspace background process that takes heavy work off the critical path of `moon` commands. While a pipeline runs, it archives task outputs to (and hydrates them from) the [remote cache](../guides/remote-cache.mdx), cleans stale cache entries, and sends [webhooks](../guides/webhooks.mdx) in the background, and between commands, it watches the workspace for configuration changes and rebuilds the [project](<../(fundamentals)/project-graph.mdx>) and [task graphs](<../(fundamentals)/task-graph.mdx>) ahead of time. See [how it works](../guides/daemon.mdx#how-it-works) for details.

The daemon does not run by default, and must be [enabled](../guides/daemon.mdx#enabling-the-daemon) with the [`unstable_daemon`](/moon/api/WorkspaceConfig#daemon) setting in [`.moon/workspace.config`](<../(fundamentals)/workspace.mdx>) (or the `MOON_DAEMON` environment variable). Once enabled, commands that run the action pipeline, like [`moon run`](./run.mdx) and [`moon exec`](./exec.mdx), transparently start it (or connect to an already-running instance), except in CI and one-off Docker containers (see [when the daemon is used](../guides/daemon.mdx#when-the-daemon-is-used)). In everyday use you won't need to run these subcommands directly. They exist for inspecting and managing the process by hand: checking whether it's up, tailing its logs, or restarting it when it seems stale.

This is a parent command and does nothing on its own; use one of the following subcommands:

- [`moon daemon start`](./daemon/start.mdx) - Start the daemon if it's not already running, reusing an existing process ID otherwise.
- [`moon daemon stop`](./daemon/stop.mdx) - Stop the running daemon, gracefully if possible.
- [`moon daemon restart`](./daemon/restart.mdx) - Stop and then start the daemon again.
- [`moon daemon status`](./daemon/status.mdx) - View the process ID, endpoint, uptime, and file paths of the running daemon.
- [`moon daemon logs`](./daemon/logs.mdx) - Tail the daemon's log file.

The daemon's own server process is launched internally (as a detached `moon daemon server` process) whenever it needs to be spawned; it's not intended to be run directly.

```shell
$ moon daemon start
$ moon daemon status
$ moon daemon logs
$ moon daemon stop
```
