---
title: moon daemon restart
---

Restart the [daemon](../daemon.mdx) by stopping the currently running process and starting a fresh one in its place.

This is equivalent to running [`moon daemon stop`](./stop.mdx) followed by [`moon daemon start`](./start.mdx), and is useful when the daemon's loaded configuration, or the [graphs it rebuilds, seem stale](../../guides/daemon.mdx#the-graphs-seem-stale) in a way its own file watcher didn't pick up. It isn't needed after upgrading moon, as a daemon running a different version is replaced automatically (see [lifecycle](../../guides/daemon.mdx#lifecycle)), and [`moon upgrade`](../upgrade.mdx) stops it for you as well. The previous process is asked to shut down gracefully first, and only killed outright if it doesn't exit in time, exactly as [`moon daemon stop`](./stop.mdx) does. Once it's confirmed gone, a new daemon process is spawned and the command waits for it to become ready, the same way [`moon daemon start`](./start.mdx) does — including failing if it doesn't become ready within the startup window.

Like `start`, this command requires the [`unstable_daemon`](/moon/api/WorkspaceConfig#daemon) setting to be enabled in [`.moon/workspace.config`](<../../(fundamentals)/workspace.mdx>) (or the `MOON_DAEMON` environment variable); if it isn't, a warning is shown and nothing happens.

```shell
$ moon daemon restart
```
