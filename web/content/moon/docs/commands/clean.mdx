title: moon clean
---

Clean the workspace by deleting stale cached items from `.moon/cache`. This is useful for
reclaiming disk space, or for troubleshooting when cached state seems out of date or corrupted. See
the [cache engine](../advanced/cache.mdx) for how the cache is structured.

`moon clean` removes the following items that are older than the `--lifetime` threshold:

- `.moon/cache/states` - The last run state and logs of each task, and project snapshots.
- `.moon/cache/locks` - Stale file locks left behind by interrupted processes.
- `.moon/cache/temp` - Temporary files used during runs.
- `.moon/cache/objects` - Hash fingerprints, as inspected by [`moon hash`](./hash.mdx), and moon's
  internal states, like the cached workspace graph.

It also garbage collects the archived task outputs in the local cache (`.moon/cache/manifests` and
`.moon/cache/blobs`, or the shared directory when
[`cache.sharedWorktreeCache`](/moon/api/CacheConfig#sharedworktreecache) is enabled). A manifest is
removed once it's older than the lifetime, or when keeping it would exceed
[`cache.cas.maxSize`](/moon/api/CacheCasConfig#maxsize), and the blobs that only removed manifests
referenced are removed with it. Blobs written within the last hour are always kept, as they may
belong to a task that's still archiving. See
[local storage](../advanced/cache.mdx#local) for how eviction works.

Remote storage backends, like a [remote cache](../guides/remote-cache.mdx), are always skipped, as
they manage their own eviction server-side. If a backend fails to be cleaned, the error is logged and
moon continues on to the next one, rather than aborting.

Passing `--all` lowers the lifetime to a single second, so effectively every item is considered
stale and removed, regardless of age.

Once cleaning has finished, moon prints how many files were deleted and how many
bytes were reclaimed.

```shell
# Delete cached artifacts older than the default lifetime (7 days)
$ moon clean

# Use a custom lifetime
$ moon clean --lifetime "3 days"

# Delete all cached items and reset local state entirely
$ moon clean --all
```

## Options

- `--all` - Clean all cached items and reset state, ignoring `--lifetime`. Can also be passed as
  `--reset`.
- `--lifetime` <TypeLabel type="string" /> - The maximum age of cached artifacts to
  keep; anything older is deleted. Accepts a human-readable duration, such as
  `"7 days"`, `"24 hours"`, or `"30 minutes"`. Defaults to `"7 days"`. Ignored when
  `--all` is passed.
