Query information about every [task](<../../(fundamentals)/task.mdx>) in the task graph, and print the result as JSON,
grouped by project, like every other [`moon query`](../query.mdx) subcommand. Tasks can be filtered either with the `[QUERY]` argument, using
[the query language (MQL)](../../advanced/query-lang.mdx), or with the individual `--option` flags below
— when `[QUERY]` is provided, it takes precedence and all filter options are ignored.

MQL is a small expression language for filtering projects and tasks with more precision than a
single regex flag allows. A statement is made up of `field operator value` comparisons — `=`/`!=`
for exact/negated matches (or `[a, b, c]` lists), and `~`/`!~` for glob-based matches — joined with
`&&`/`AND` or `||`/`OR`, and grouped with parentheses. The fields that apply to tasks are `task`,
`taskType`, `taskTag`/`taskTags`, `taskToolchain`/`taskToolchains`, and `project`, which matches the
ID or an alias of the task's owning project. Other project fields, like `projectId`, never match a
task. See the [query language docs](../../advanced/query-lang.mdx) for the full field and operator
reference.

When no `[QUERY]` is given, the `--option` filters are applied instead, where every value is treated
as a case-insensitive regular expression matched against the relevant task field.

```shell
# List every task in the workspace, grouped by project
$ moon query tasks

# Find tasks whose ID matches "build"
$ moon query tasks --id build
$ moon query tasks "task~build"

# Find tasks that belong to a project matching "app"
$ moon query tasks --project app

# Find tasks affected by changed files
$ moon query tasks --affected
```

The output is a JSON object with a `tasks` map (project ID to a map of task ID to full
[task](<../../(fundamentals)/task.mdx>) configuration object) and the resolved `options` that were used to produce them.

## Arguments

- `[QUERY]` - An [MQL statement](../../advanced/query-lang.mdx) to filter tasks with. When provided, all
  filter options below are ignored.

## Options

### Affected

- `--affected` <TypeLabel type="boolean | string" /> - Filter down to only tasks affected by changed
  files. When passed without a value, changed files are detected from the local working tree (or
  piped in via stdin, as produced by [`moon query changed-files`](./changed-files.mdx)); a string value
  further customizes the comparison, using the same syntax as the
  [`moon query affected`](./affected.mdx) `[BY]` argument. Each task's
  [`options.runInCI`](/moon/api/TaskOptionsConfig#runinci) setting is respected: in CI, tasks that
  don't run in CI are never affected, and tasks set to `always` are always affected, while outside
  of CI, tasks set to `only` are never affected.
- `--dependents` <TypeLabel type="none | direct | deep | number" /> - Include the tasks that
  depend on affected tasks, up to this many hops away, by propagating affected state to them (see
  [tracking depth](../../advanced/affected.mdx#tracking-depth)). Defaults to `none`. Requires
  `--affected` to also be passed.
- `--dependencies` <TypeLabel type="none | direct | deep | number" /> - Include the tasks that
  affected tasks depend on, up to this many hops away. These are included in the results, but
  aren't marked as affected. Defaults to `none`. Requires `--affected` to also be passed.

### Filters

All values below are matched as case-insensitive regular expressions, and are ignored when
`[QUERY]` is provided.

- `--command` <TypeLabel type="string" /> - Filter tasks whose command matches this pattern.
- `--id` <TypeLabel type="string" /> - Filter tasks that match this ID.
- `--project` <TypeLabel type="string" /> - Filter tasks that belong to a project matching this
  pattern.
- `--script` <TypeLabel type="string" /> - Filter tasks whose script matches this pattern.
- `--tags` <TypeLabel type="string" /> - Filter tasks that have a tag matching this pattern.
- `--toolchain` <TypeLabel type="string" /> - Filter tasks that use a toolchain matching this
  pattern.
- `--type` <TypeLabel type="string" /> - Filter tasks of this type.
