---
title: moon migrate v2
---

Migrates an existing moon v1 workspace to moon v2 by rewriting all `.moon` YAML configuration files (workspace, toolchain,
tasks, and per-project `moon.yml` files) in place to match the v2 schema. Because every touched
file is parsed and then re-serialized, comments are stripped and formatting is normalized as part
of the migration, so it's a good idea to run this against a clean git working tree and review
the diff before committing. To then migrate from v2 to v3, run
[`moon migrate v3`](./v3.mdx).

By default the command prompts for confirmation before making any changes:

```shell
$ moon migrate v2
```

Pass `--yes` to skip the prompt entirely (useful in CI or scripting):

```shell
$ moon migrate v2 --yes
```

`.pkl` based configuration files are detected but cannot be automatically migrated. A
warning is logged (once per run) for each `toolchain.pkl`, `workspace.pkl`, `tasks.pkl`,
or `moon.pkl` file found, and that file is left untouched.

## Options

- `--yes` - Skip the confirmation prompt and apply all migrations immediately.
